# Gateway Evidence Linux Builder

This container is the native Linux validation envelope for the gateway evidence crate. It deliberately starts from the immutable official Rust 1.82.0 image used by the project and adds only CMake, which the locked bundled `zeromq-src` dependency requires.

It is not the final OpenWrt cross-toolchain. The final Raspberry Pi `bcm27xx/bcm2709` binary must still be linked with the toolchain generated by the pinned ChirpStack Gateway OS v4.12.0 / OpenWrt tree. The OpenWrt GCC produced by this project requires host GLIBC 2.38 or newer; therefore the cross-build must run either directly on a sufficiently new Linux host or inside a separate compatible builder. The native Rust-validation image remains intentionally unchanged because its immutable Rust 1.82 identity is already proven.

Build on the Linux build VM:

```sh
docker build -t lorawan/gateway-rust-builder:1.82.0 packaging/build
```

Then mount the crate source plus persistent Cargo/target cache and run the normal locked gates, including `--features concentratord-zmq`. Record the resulting builder image ID/digest with build evidence.
