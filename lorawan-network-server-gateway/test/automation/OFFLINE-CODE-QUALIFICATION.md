# Offline Test-Code Qualification — 2026-09-21

## Scope and limits

This batch never touches the gateway, sensors or live servers—even when the equipment is connected. It validates the research **test implementations** with fixed contracts, synthetic/saved evidence, isolated local mock MQTT traffic, and failure-path assertions. No real RF, LTE, ChirpStack decision, PostgreSQL/Fabric commit, service failover, or production flooding is claimed. Every output has `qualification=CODE_ONLY`, `counted_research=false`, and `hardware_measurements=false`.

Run from the `lorawan-network-server-gateway` repository root on the project Windows workstation:

```powershell
py -3 test/automation/run_offline_qualification.py
```

One command runs explicitly allowlisted suites **sequentially**, exits nonzero if any suite fails or reports zero tests, and writes a fresh `chapter4-results/code-qualification/offline-code-<UTC>/code-only-summary.json` and one pair of stdout/stderr logs per suite. It has no live deployment hooks. The MQTT wire tests communicate only with an in-process loopback mock. Do not run the live/manual test entry points to reproduce this qualification.
